Entities (tile 0–24, one per tile)

Transporters

One byte per teleport, destination room, in the order teleports appear across rooms 0…n.

Switch influence

3 bytes: elements-in-room, switch-at-room, mask (bit7 enemy1 … bit0 floor5).

C export
